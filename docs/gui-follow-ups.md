# GUI follow-ups

## Typography

Evaluate where a monospace face helps and where a proportional face would make
the application easier to read. Keep the current app typography until that
comparison is ready. Inline Markdown code enclosed in single backticks must
remain visually distinct from surrounding prose, using a different monospace
face or a quiet background. The code renderer provides a background in this
iteration; broader font selection remains a separate design task.

## Shared menus

Revisit the visual treatment of menus after the current Library refinements.
Cover right-click context menus, three-dot menus and other shared menu surfaces
together. Compare density, padding, grouping, separators, type size, focus and
hover states, submenus, disabled actions, destructive actions, and tooltips.
Use the same treatment throughout the application and evaluate both themes.
Keep current menu behavior while the replacement appearance is being chosen.
